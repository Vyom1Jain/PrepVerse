# Infrastructure

This folder contains infrastructure, deployment, and DevOps configuration for PrepVerse.

## Contents
- Docker configurations
- CI/CD pipelines (GitHub Actions)
- Environment setup scripts
- Database migrations
- Deployment configurations for free hosting platforms

## Deployment Platforms (Free Tier)
- **Frontend**: Vercel / Netlify / GitHub Pages
- **Backend**: Render / Railway (free tier)
- **Database**: Neon / Supabase (PostgreSQL free tier)
- **File Storage**: Cloudinary / Supabase Storage (free tier)
- **AI Services**: OpenAI API / Google Gemini API

## CI/CD Pipeline
- Automated testing on pull requests
- Automatic deployment to staging/production
- Database migration automation

## Environment Variables
See `.env.example` files in respective folders for required environment variables.
