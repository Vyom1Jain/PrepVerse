# Backend

This folder contains the backend API and services for PrepVerse.

## Tech Stack
- Node.js / Python (FastAPI)
- Database: PostgreSQL (free tier: Neon/Supabase)
- Authentication: JWT
- AI Integration: OpenAI API / Google Gemini API (free tier)

## Features
- User authentication and authorization
- Progress tracking API
- AI-powered study planner algorithm
- Question bank management (500+ DSA questions)
- GATE papers repository (20 years)
- Admin dashboard for content management
- Analytics and reporting APIs
