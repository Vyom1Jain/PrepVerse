# Frontend

This folder contains the frontend application for PrepVerse.

## Tech Stack
- React.js / Next.js (for SSR/SSG)
- UI Framework: Tailwind CSS / Material UI
- State Management: Redux / Zustand
- Charts/Visualization: Chart.js / Recharts
- Code Editor: Monaco Editor (for coding practice)

## Features
- Interactive dashboard with progress tracking
- AI-powered personalized study planner
- Roadmap visualization (GATE, Placement, DSA, System Design)
- 500+ DSA question bank with filters and search
- 20 years of GATE papers with solutions
- Quiz system with timer and analytics
- Video content integration (YouTube embeds)
- Admin panel for content management
- Responsive design for mobile and tablet
- Dark/Light mode toggle

## Pages/Routes
- `/` - Home/Landing page
- `/dashboard` - User dashboard
- `/planner` - AI Study Planner
- `/roadmaps` - Career roadmaps
- `/dsa` - DSA questions
- `/gate` - GATE preparation
- `/system-design` - System design section
- `/profile` - User profile and settings
- `/admin` - Admin dashboard (protected)
